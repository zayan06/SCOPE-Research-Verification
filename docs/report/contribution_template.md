## Student-written narrative prompts

- What did each person plan and carry out?
- Which shared tasks were completed jointly, and how were they divided?
- Who reviewed code, labels, results, and references?
- Which parts are incomplete or were revised after review?
- What evidence supports each contribution statement?

The supervisor and students should adapt the table to university policy. Do not equate tool-produced drafts or code with student-authored academic analysis without substantive student review and revision.
